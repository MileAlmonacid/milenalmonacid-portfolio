# Milenalmonacid Portfolio

Crea una página de inicio para el portafolio profesional de una Senior Software QA Engineer con un diseño ultra moderno "SaaS Dark Mode". 

Fondo principal oscuro profundo (#0A0E17). Usa una tipografía Sans-Serif limpia y audaz.

Estructura de la página:

1. Navbar minimalista: Un logo estilizado de código a la izquierda "</>", enlaces centrales (Home, About, Experience, Skills, Contact) y un botón elegante a la derecha con un icono de descarga que diga "Descargar CV".

2. Sección Principal (Hero):

- Un título grande y contundente a la izquierda: "Garantizando la Calidad del Software. Maximizando el Impacto Digital."

- Dos líneas introductorias debajo: "Ingeniera de Sistemas experta en QA Manual y Automatización. Conectando metodologías ágiles, pruebas exhaustivas y optimización de procesos para asegurar lanzamientos sin errores."

- Un botón de acción principal que sea interactivo con efecto hover.

3. Sección de Pilares (3 Tarjetas con bordes finos de neón azul):

- Tarjeta 1: Icono lineal de un check o escudo. Título: "Metodología QA". Descripción corta sobre planificación, análisis de requerimientos y estrategias de pruebas eficaces.

- Tarjeta 2: Icono de un engranaje o código. Título: "Automatización y APIs". Descripción sobre pruebas funcionales, automatizadas y testing de APIs para robustez del software.

- Tarjeta 3: Icono de un rayo o grupo de personas. Título: "Agile & DevOps". Descripción sobre integración en entornos Scrum/Kanban y mejora continua en el ciclo de vida del desarrollo.

4. Sección Destacada (Frase en comillas grandes al fondo):

"La calidad no es un acto, es un hábito. Asegurar la excelencia del software es el puente entre el código y la confianza del usuario."
